# DLSS5 一键开启工具

DLSS5一键开启工具（DLSS5 One‑Click Enabler）是一个用 Go 编写的命令行工具，旨在帮助用户快速检测并切换系统或应用中与 DLSS5 相关的设置。该仓库提供了构建、使用、调试说明与常见问题解决思路，便于开发者编译或二次开发。

> 说明：README 中给出的命令与参数为通用示例；请根据仓库代码中的实际命令行参数或子命令进行调整。

---

## 特性

- 用 Go 实现的轻量级命令行工具
- 检测系统/硬件是否支持 DLSS（基于驱动/显卡信息）
- 一键开启或关闭 DLSS5（视系统权限与支持情况）
- 支持输出当前 DLSS 状态和日志以便调试

---

## 先决条件 / 依赖

- Go 1.20+ 开发环境（用于编译）
- 支持 DLSS 的 NVIDIA GPU（如需实际开启 DLSS）
- 合适的操作系统驱动（NVIDIA 驱动）与权限（可能需要管理员/root 权限）
- Windows / Linux 下的系统接口权限 —— 具体依赖视实现而定

## 快速开始

1. 克隆仓库
```bash
git clone https://github.com/metal-vest/DLSS5.git
cd DLSS5
```

2. 本地编译（示例）
```bash
# 在仓库根目录下构建可执行文件（根据项目实际包名或 main 目录调整）
go build -o dlss5 .
```

3. 运行（示例）
```bash
# 显示帮助
./dlss5 --help

# 检查当前系统 DLSS 支持 / 状态
./dlss5 status

# 一键开启 DLSS5（可能需要管理员权限）
sudo ./dlss5 enable

# 关闭 DLSS5
sudo ./dlss5 disable
```

## 常见问题（FAQ）

Q: 我运行 `enable` 后没有生效怎么办？
A: 请确认你使用的是支持 DLSS 的 GPU、驱动已更新、并且以管理员权限运行；查看日志以获取错误信息。

Q: 这个工具会修改游戏/应用文件吗？
A: 工具的具体行为取决于实现。理想情况下应尽量通过系统或驱动接口切换设置，而不是直接修改游戏文件。请检查代码与日志确认实际操作。

Q: 支持哪些平台？
A: 参考仓库实现，工具在不同系统上所需的系统调用与权限不同。默认目标平台请参见代码或 issue。
